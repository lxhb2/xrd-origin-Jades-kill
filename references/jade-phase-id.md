# Jade 6.5 物相检索与 PDF 卡片导出

Jade 6.5 本身是图形界面软件，但本 skill 已用 Win32/pywinauto 封装了常用检索步骤。优先使用 `scripts/jade_phaseid.py`，下面的人工步骤作为版本差异或自动化失败时的回退。

版本差异：本文以 MDI Jade 6.5（经典版）为主，这是国内课题组最常用的版本。JADE 9+ 是重写版，菜单结构不同，遇到 9.x/Pro 版本时按实际界面调整，不要照搬菜单名。

## 零、调用前必须确认

必须先向用户取得目标元素和化学式。若用户不知道，先问样品信息或研究方向，再查相关论文和公开资料归纳常规元素/化学式，不要直接从谱图猜物相，也不要替用户确认物相归属。

```text
python scripts/jade_phaseid.py search ^
  --out ./jade_out ^
  --elements "Si,Fe,Cu,S" ^
  --formula "Si + FeS2 + CuFeS2" ^
  --filter-mode possible ^
  --export-card 75-0589 ^
  --export-card 71-1680 ^
  --export-card 75-0253
```

- `possible`：元素可以作为任一候选相的一部分，混相样品的默认选择。例如目标为 Si + FeS2 + CuFeS2 时，候选相不必同时含 Si/Fe/Cu/S。
- `required`：每个候选相都必须含全部目标元素，仅适合单相或所有物相共享同一元素集的特殊情况。
- 默认自动执行 Find Peaks；只有用户已经人工确认峰位时才用 `--reuse-peaks`。
- 如果 Jade 询问是否自动扣背景，脚本选择 `No`，因为它不替用户改动谱图数据。
- 脚本输出 `candidates.csv/json`、`search_request.json` 和可选 `cards/*.txt`。候选表不是物相结论。

## 前置条件

- 必须装有 PDF 数据库（ICDD，PDF-2 / PDF-4 / PDF-5+ 任一）才能做检索；只有软件没有库时检索功能不可用。
- 数据库版本决定了能检索到的卡片范围，也决定了卡片号写法，写论文时要如实标注用的哪个库。

## 一、导入数据

1. 打开 Jade，`File → Patterns…`（或直接把 `.raw` 拖进窗口）。
2. 左侧选文件夹，文件类型选 `All` 或对应格式（`.raw`/`.asc`/`.txt`）。
3. 左键双击文件完成导入。
4. 同一目录的其他数据会列在窗口左侧，双击即可切换，不必重复导入。

## 二、检索

### 自动脚本（优先）

脚本会打开或复用本机 Jade，执行 Find Peaks，设置 `Current Chemistry` 元素筛选，调用 Search/Match，再从 `Search/Match Display` 读取候选，并在结束后恢复用户原来的 `jade6.cff` 筛选文件。

使用前确认：

1. Jade 当前已打开目标 XRD 文件；也可以给 `search` 增加 `--pattern "D:\...\sample.raw"`。
2. Python 环境已安装 `pywinauto` 和 `pywin32`。
3. 输出目录中的 `search_request.json` 能追溯本次样品的元素、化学式和筛选模式。

### 人工回退

### 无条件检索（先做这一步）

1. 点工具栏 `S/M`（Search/Match）。
2. 弹出是否做背景（基线）处理的询问：**不改数据就选 No**。
3. 在 `Search/Match Display` 窗口里按 **FOM**（品质因数）排序查看，FOM 越小表示匹配度越高。
4. 双击候选卡片打开卡片信息窗口，看峰位与相对强度是否吻合。

### 限定元素检索（推荐，尤其是已知元素组成时）

1. 在软件首页右键 → 勾选 `Use chemistry filter`。
2. 选样品所属分类 → OK。
3. 在元素周期表里选样品实际含有的元素 → OK。
4. 再检索，候选范围会大幅缩小。

### 单峰检索（还有对不上的峰时）

1. 主窗口点「计算峰面积」，在峰下划一条底线把峰框出。
2. 右键点 `S/M`，检索对象变为该峰（Jade 5 里显示为 `Painted Peaks`）。
3. 软件列出在该 2θ 位置有衍射峰的所有标准卡片，从中找可能的物相。

## 三、怎么判断“匹配上了”（关键）

FOM 最小 **不等于** 物相正确。逐条核对：

| 检查项 | 说明 |
| --- | --- |
| 三强峰位置 | 标准卡的三强峰与实测峰位是否都对得上（允许仪器零点/样品位移带来的小偏移） |
| 相对强度 | 前几个强峰的高低顺序是否大致一致；严重偏离常见于择优取向 |
| 元素约束 | 样品里没有的元素，不可能形成对应的相；用元素过滤排除 |
| 多相共存 | 先定主相，再在剩余未归属的峰上找次相，别用一张卡片硬套全部峰 |
| 系统性偏移 | 所有峰整体平移 → 固溶、掺杂、应力或零点问题，不是“匹配失败” |
| 个别弱峰对不上 | 可能是低含量杂相，也可能是伪峰、噪音或 Kβ 残留 |

不确定时：给出候选相、吻合与不吻合的地方，让用户结合合成条件、元素分析和文献决定。不要替用户下结论。

## 四、卡片数据处理

检索用的 Kα2 剥离、扣背景、平滑都会改变数据：

- 检索可以在处理后做（信噪比更好），但处理后得到的峰位/峰强与原始数据不再等价，出图和写论文时要说明做过什么处理。
- 晶粒尺寸用 Scherrer 公式 `D = Kλ/(β cosθ)`（β 为半高宽，K≈0.89）：β 必须先扣除仪器展宽，结果是估算值，一般小于 SEM/TEM 观察到的粒径。Jade 里可点拟合按钮后直接读数，但要在文中写明假设。

## 五、导出 PDF 卡片

自动导出优先：

```text
python scripts/jade_phaseid.py export-card --out ./jade_out --pdf 75-0589 --pdf 71-1680 --pdf 75-0253
```

脚本从 Jade 的 PDF Retrieval 结果行打开对应卡片，只保存 d-I 峰表。人工导出步骤：

1. 在卡片信息窗口里切到 **Line** 视图。
2. 点右侧的**保存按钮**（软盘图标）→ 选路径 → 存为 TXT。
3. 换其他需要的物相重复导出；相似样品可共用同一张卡片，不必重复导出。
4. 用记事本打开 TXT，删掉开头的卡片描述、作者、实验条件等说明，只留峰位表：
   - 常见表头：`d(A) / I(f) / h k l` 或 `2-Theta / d / I(f)`
   - 作图只需要 2θ 与 I 两列；`scripts/xrd_stack.py` 也能自动跳过头部并按需换算 d→2θ
5. 保存规范：文件名用物相名，例如 `beta-PbO2_PDF00-041-1442.txt`；卡片号以当前数据库显示为准。

## 六、卡片号写法

- 现行 ICDD 卡片号是三组：`ICDD No. XX-XXX-XXXX`（例如 `00-041-1442`）。
- 老文献里的两组号（如 `JCPDS 89-1492`）是旧编号体系；同一物相的现行编号可能已经变了（例：`JCPDS 89-1492` 现为 `PDF 04-004-4342`），引用时以数据库当前显示的号为准，别直接抄旧文献。
- 图中标注建议同时给“物相名 + 卡片号”，如 `β-PbO₂ (PDF#00-041-1442)`。

## 七、常见坑

| 现象 | 原因 / 处理 |
| --- | --- |
| 检索不到任何合理相 | 没装数据库；或元素过滤选错了元素；或数据质量太差（先扣背景/平滑再试） |
| FOM 很小但明显不是该物相 | FOM 只是匹配程度的启发式指标，必须用三强峰 + 元素约束人工复核 |
| 峰位整体偏移 0.1°–0.3° | 样品位移、仪器零点、或固溶导致；重新做标准样校正，或如实说明 |
| 强峰对得上、弱峰全都不见 | 常见于择优取向或结晶度差，需要在文中说明，而不是当成匹配成功 |
| 混相样品只匹配出一相 | 用单峰检索处理剩余峰，或者限定元素后再检索 |
| 把卡片数据拿去外发 | ICDD 数据库受版权保护；对外只给峰位表或图，不要整库转发 |
