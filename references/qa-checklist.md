# 出图与投稿检查清单

## 出图前（数据层面）

- [ ] 每一条曲线的 2θ 与强度列选对了（不是把 2θ 当强度、或把两列样品弄反）
- [ ] λ 与仪器一致；如果卡片是 d 值换来的，换算用的 λ 已记录
- [ ] 是否做过扣背景、Kα2 剥离、平滑：做过就要能说清楚，并在图注/实验部分写；
- [ ] 归一化方式明确（脚本 manifest 里已记）
- [ ] 卡片数据来自授权数据库，卡片号是数据库里实际显示的号，没凭记忆写
- [ ] 实验卡与 Calculated(C) 卡已区分；计算卡没有被写成实验卡片
- [ ] 已记录数据库版本、元素筛选模式和峰位/强度是否经过背景、平滑或 Kα2 处理
- [ ] 卡片与样品的对应关系是用户确认的，不是自动猜的
- [ ] 成图平滑参数已记录；确认原始强度表和 Origin 数据仍保留未平滑值

## 出图后（视觉层面）

- [ ] 打开 PNG 亲眼看过（脚本产出必须视觉确认，不能只看 exit code）
- [ ] 卡片竖线与样品峰位按同一 2θ 标尺对齐，没有整排偏移
- [ ] 曲线之间峰不互相遮挡；每条曲线的基线与下方竖线带不重叠
- [ ] 下方每张卡片各占一层，水平基线不粘连，标签使用化学式且不压棒状图，也不贴近层顶
- [ ] 所有 PDF 卡片棒状线、基线、化学式和 PDF# 标签都在同一个坐标框内，没有任何标签伸到框外
- [ ] 卡片层距足够紧凑但棒线不粘连；棒线过高时已压缩，过弱峰已按显示阈值省略，原始卡片表仍完整
- [ ] 英文字体为 Times New Roman（或期刊指定等效字体），字号在最终尺寸下可读；中文字体正常显示，不是方框或乱码
- [ ] X 轴范围覆盖全部主峰（常见 10°–80°），主刻度整齐（如 10°）
- [ ] 图框闭合；上边框无刻度线；底部 X 刻度朝内；纵轴无刻度数字、Y 轴标题为 `Intensity (a.u.)`
- [ ] 单条谱的卡片图例不压曲线；多条谱的右侧样品名不压峰
- [ ] 分层卡片图没有重复放一个放大图例；若显式启用图例，图例仍在框内且不压峰
- [ ] 卡片化学式与对应卡片一致；需要时在图注补齐卡片号
- [ ] 单谱使用符号标峰时，每个符号对应同一张卡片，图例写清化学式与 PDF 号
- [ ] 单谱使用 hkl 标峰时，晶面指数来自指定卡片，负指数和重复峰已人工复核
- [ ] 单谱启用标峰时，下方 PDF 卡片棒状图和卡片标签已隐藏；多样品堆叠图仍保留卡片层

## 投稿前

- [ ] 位图分辨率 ≥ 300 dpi（多数期刊要求 600 dpi），矢量图已保留 PDF/EPS
- [ ] 单栏图宽度约 8–9 cm、双栏约 17 cm；字体缩到最终尺寸后仍可读（通常 ≥ 6–7 pt）
- [ ] 图注写明：X 射线源与波长、是否归一化、卡片来源（数据库与卡片号）
- [ ] 所有在图里出现的物相，正文都有对应的说明或引用
- [ ] 缺少 XRF/EDS 或文献证据的相已标为 `candidate`
- [ ] 没有把标准卡片的相对强度当成相含量（半定量需要 RIR 或全谱拟合）

## 容易被审稿人问到的点

- “这个峰归属有依据吗？”——准备好三强峰对应关系与元素约束。
- “弱峰为什么没标？”——如果确实有未归属峰，说明是杂相、噪音还是 Kβ。
- “为什么用 a.u. 纵轴？”——归一化后强度不可比绝对计数，a.u. 是正确写法。
- “卡片号是哪一版数据库的？”——写清数据库版本（PDF-2/PDF-4+ 等）。
