# 在 Origin 里画 XRD 堆叠图

XRD 堆叠图的默认形态：多条谱线沿 Y 方向依次偏移；所有物相的标准卡片统一放在下方，每张卡片单独占一层，用水平基线分隔。竖线位置 = 标准峰 2θ，线高 = 相对强度。

## 自动生成可编辑 OPJU（优先）

先用 `scripts/xrd_stack.py` 解析谱线与卡片，并生成 Origin 友好的数据表：

```text
python scripts/xrd_stack.py --sample "样品1=raw/s1.txt" --sample "样品2=raw/s2.txt" --card "黄铁矿_PDF71-1680=jade/feS2.txt" --out ./figs/xrd
```

再调用 `scripts/origin_stack.py`：

```text
python scripts/origin_stack.py --origin-dir ./figs/xrd/origin --out ./figs/xrd_origin --x-range 10 80
```

输出：

- `xrd_origin.opju`：可继续编辑的 Origin 工程；
- `xrd_origin.png` 与 `xrd_origin.pdf`：预览与矢量导出；
- `origin_run.json`：样品、卡片、偏移量和输出路径记录。

卡片竖线由 Origin 的折线“分段连接”生成，每一对同 x 的上下点画成一条竖线，最后再补一对端点画该卡片层的水平基线；不要改回普通连续折线，否则峰间会出现错误的水平连线。
卡片标签优先使用 `manifest.json` 或 `Sheet2_cards.csv` 里的化学式，放在主图右侧，不与棒状图区域重叠。

若 `xrd_stack.py` 使用了 `--peak-marking markers`，Origin 脚本会读取 `Sheet3_peak_annotations.csv`，为每张卡片建立可编辑的散点标峰图层；若使用 `--peak-marking hkl`，则把 `(hkl)` 文本放到对应实测峰上。两种标峰都只适用于单条 XRD 谱；启用后 Origin 脚本会跳过 `PDF_Cards` 工作表和卡片棒状图图层，也不再添加卡片右侧标签。多样品堆叠图不使用单谱标峰，仍会保留下方卡片棒状图层。

运行前保存并关闭已有的 Origin 工程；若确认要复用当前进程，显式加 `--allow-existing`。如果导出的 PNG 出现重复 `demo` 水印，检查 Origin 是否已激活；这是本机许可证状态，不是脚本加入的标签。

## 三种做法

| 做法 | 适合 | 代价 |
| --- | --- | --- |
| 脚本出图 + Origin 微调 | 大多数情况（推荐） | 需要 Python + matplotlib；要在 Origin 里大改需重做 |
| Origin 纯手工（Y 偏移堆积线图） | 用户想自己全程操作、后续频繁调整 | 手工步骤多，容易在偏移与对齐上出错 |
| 多图层法 | 卡片较多、要在一张图里精确对齐多组竖线 | 图层管理复杂 |

脚本会把数据按 Origin 的列习惯导出到 `origin/` 目录（`Sheet1_samples.csv` 样品、`Sheet2_cards.csv` 卡片），可以直接按下面的手工流程重做一遍。卡片行高和竖线比例默认从 `manifest.json` 的 `layout` 读取。

## 菜单用词说明

下面方括号里的中文菜单名已按本机 **Origin 2025b 中文界面**核对（绘图类型列表、模板 `OffsetStackY.otpu`、绘图细节控件索引）。其他版本用词可能略有差异，遇到不一致时以用户界面为准。

## 做法一：Y 偏移堆积线图（手工）

1. **整理数据**：新建工作簿，每个样品占两列（第一列 2θ，右键 → 设为 X；第二列强度）。样品依次排开：A/B 为样品 1，C/D 为样品 2……批量导入用 `文件 → 导入 → 多个 ASCII`，导入后删掉无关列。
2. **出雏形**：选中所有样品的两列 → `绘图 → 基础 2D 图 → Y 偏移堆积线图`【Y Offset Stacked Lines】。
3. **让偏移可控**：双击图形 → `绘图细节` → `图层属性` → `堆叠` 选项卡 → `偏移` 选 **“单独”**。
   - 可选值：`无 / 累积 / 常量 / 自动 / 单独 / 增量`，另有 `间距(%)`。
   - 也可用图层右键 → `图层中组数据偏移模式 → 单独`。
   - **不选“单独”，所有曲线会锁在一起，拖不动单条曲线。**
4. **调间距**：鼠标点住单条曲线上下拖动，让峰之间互不遮挡。
5. **卡片统一下移**：把所有卡片数据放在主图下方，每张卡片占一行。可以给每行加一条细水平基线，并在右侧标注物相名。
6. **美化**：
   - 线宽：双击曲线 → `线条` → 宽度（论文常见 1.5–2.0）；
   - 坐标轴：X 轴范围覆盖全部主峰（常用 10°–80°），刻度线朝内，主刻度 10°；
   - 图框：保留完整闭合边框，不要只留两条轴线；
   - 纵轴：只留 `Intensity (a.u.)`，隐藏 Y 刻度数字，不标绝对强度。

## 做法二：卡片竖线（复制小图法）

1. 选中一张卡片的 2θ 与相对强度两列 → `绘图 → 基础 2D 图 → 散点图`。
2. 双击图形：符号大小设为 0，`线条` 设为 `无线条`。
3. `垂直线` 选项卡 → 勾选 **平行于 Y 轴**，宽度设 2–3，颜色与对应曲线一致。
4. X 轴范围必须与主图完全一致（例如都是 10–80），否则复制过去对不齐；卡片小图不要轴标题。
5. 复制整张小图 → 切到主图 → 粘贴 → 拉伸定位。
   - **只做水平或垂直拉伸，不要对角线拉伸**，否则峰位会错位。
   - 竖线高度可在小图里通过压缩 Y 轴范围控制。
6. 逐张卡片重复，最后统一微调颜色与卡片名（如 `β-PbO₂ (PDF#00-041-1442)`）。

## 做法三：多图层法

1. 堆叠图做好后，双击图层编号 `1` → 图层管理 → 新建图层 → 右 Y 轴（关联 X 轴刻度与尺寸）。
2. 在新图层里加入卡片数据列，绘图类型设为散点图。
3. 双击散点：符号大小 0、无线条、勾选 `垂直线`（平行于 Y 轴）、设置宽度与颜色。
4. 把该图层压扁放在主图下方，X 轴刻度设为无；多张卡片就再建图层 3、4……

## 常见故障

| 现象 | 原因 / 处理 |
| --- | --- |
| 曲线拖不动、一拖整组动 | 偏移没设“单独”：绘图细节 → 图层属性 → 堆叠 → 单独 |
| 卡片竖线与 XRD 峰对不上 | 小图与主图 X 轴范围不一致；或卡片给的是 d 值没换算成 2θ |
| 竖线高低不统一 | 各卡片强度基准不同；统一按最强峰 = 100 归一化（`xrd_stack.py` 默认已做） |
| 复制进去的图变形 | 用了对角线拉伸；改为只做水平/垂直拉伸 |
| 竖线朝下（倒挂） | 卡片图 Y 轴被设为反向：双击 Y 轴 → 刻度 → 取消“反向” |
| 数据列太多太乱 | Ctrl+左键多选无关列删除；2θ 列右键 → 设为 X |
| 中文显示为方框 | 脚本出图用 `--font "Microsoft YaHei"`；Origin 里改轴标题字体 |

## 导出

`文件 → 导出图形`：位图用 TIFF/PNG（≥300 dpi，投稿常用 600 dpi），矢量用 PDF/EPS。两者各存一份。
